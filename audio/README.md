# 🎧 Áudio — Ambientes Sonoros & Soundscapes

Este diretório reúne paisagens sonoras, texturas auditivas e experimentações acústicas criadas para o universo **Lenses in Focus**.

## 📁 Conteúdos
- **Soundscapes** — ambientes sonoros imersivos  
- **Texturas auditivas** — camadas e ruídos criativos  
- **Elementos experimentais** — sons abstratos e manipulações digitais  
- **Design acústico** — composições focadas em atmosfera e sensação

## 🎯 Objetivo
Criar experiências auditivas que dialogam com elementos visuais, texturas digitais e presets, formando ambientes completos e sensoriais.

## 🛠️ Como usar
- Combine com visuais de `/visual` para criar peças audiovisuais  
- Utilize texturas de `/textures` para enriquecer atmosferas  
- Integre com presets de `/presets` para criar novos estilos sonoros
