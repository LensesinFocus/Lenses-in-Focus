# 🧩 Texturas — Materiais Visuais & Ambientes Digitais

Este diretório reúne materiais visuais, superfícies digitais e elementos que ajudam a construir atmosferas imersivas dentro do universo **Lenses in Focus**.

## 📁 Conteúdos
- **Texturas digitais** — padrões, ruídos e superfícies visuais  
- **Materiais abstratos** — elementos para composição e sobreposição  
- **Ambientes visuais** — bases para cenários e atmosferas  
- **Camadas experimentais** — efeitos e manipulações criativas

## 🎯 Objetivo
Fornecer elementos visuais que complementam áudio, presets e composições, criando ambientes ricos e multidimensionais.

## 🛠️ Como usar
- Combine com visuais de `/visual` para criar profundidade  
- Use com áudio de `/audio` para formar experiências sensoriais  
- Misture com presets de `/presets` para novos estilos visuais
