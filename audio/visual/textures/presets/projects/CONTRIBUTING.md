# 🤝 Contribuindo para o Lenses in Focus

Obrigado por considerar contribuir com este projeto!  
Siga estas orientações para manter tudo organizado e consistente.

## 🧩 Estrutura
Cada contribuição deve respeitar a organização atual:
- `audio/` — soundscapes e ambientes sonoros  
- `visual/` — composições visuais  
- `textures/` — materiais e texturas digitais  
- `presets/` — ferramentas e presets  
- `projects/` — projetos completos  

## 📝 Como contribuir
- Crie uma branch com um nome claro (ex: `feature-novo-visual`)
- Faça commits pequenos e bem descritos
- Abra um Pull Request explicando o que foi alterado

## 📐 Padrões
- Use nomes de arquivos claros e consistentes  
- Evite duplicar conteúdo  
- Mantenha o estilo visual e sonoro do projeto  

## 📬 Contato
Para dúvidas, sugestões ou ideias, abra uma **Issue** no repositório.
