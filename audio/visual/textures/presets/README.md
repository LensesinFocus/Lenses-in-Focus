# 🎛️ Presets — Ferramentas & Estilos Visuais/Sonoros

Este diretório reúne presets criativos usados para transformar, modular ou estilizar elementos do universo **Lenses in Focus**.

## 📁 Conteúdos
- **Presets visuais** — ajustes de cor, filtros e estilos gráficos  
- **Presets sonoros** — efeitos, modulações e transformações auditivas  
- **Ferramentas híbridas** — presets que combinam áudio e visual  
- **Experimentos** — configurações não convencionais para exploração criativa

## 🎯 Objetivo
Oferecer ferramentas rápidas para criar estilos consistentes, acelerar processos criativos e manter a identidade estética do projeto.

## 🛠️ Como usar
- Aplique em elementos de `/visual` para criar atmosferas únicas  
- Combine com áudio de `/audio` para formar experiências sensoriais  
- Misture com texturas de `/textures` para resultados mais profundos
